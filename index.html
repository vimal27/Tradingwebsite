All trades
Reports are calculated from the trade history, aggregating each market's net P&L by date. Positive daily P&L counts as a target/profit day; negative as a loss day; zero on a date with trades as a no-P&L day. Total trading days shows the full exchange calendar for the month; no-trade days count only elapsed trading days with no entry. Weekends and NSE trading holidays are excluded. Accuracy is profitable days divided by days with non-zero P&L.

Export a backup

Download your trades and sprint-planning data as a portable JSON file. Your data is never uploaded or shared.

Local storage

Trades and sprint-planning data are stored in this browser's local storage as JSON. Opening this page in a different browser or clearing browser data will not carry them over.

For a fully portable copy, export a JSON backup regularly. Importing a full backup replaces the current local data after confirmation. This standalone page makes no network requests.
